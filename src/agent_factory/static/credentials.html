Доступ до AI

Ключ зберігається у сховищі облікових даних Windows вашого користувача. Збереження ключа ще не дозволяє запуск AI чи витрати.

Не вставляйте ключ у задум гри, повідомлення чи звіт. Не відкривайте інструменти запису мережі під час введення. Для скриншота спочатку очистьте поле.

Збережений доступ

Відключення блокує нові виклики тут. Поточний виклик може завершитися до відключення. Щоб відкликати інші копії ключа, видаліть або замініть його в обліковому записі провайдера. Ця дія не відкликає ключ у провайдера автоматично.

Відключити цей доступ?

Нові виклики з цим підключенням буде заблоковано.
