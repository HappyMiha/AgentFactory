# Repository guidance

Read [CONTRIBUTING.md](CONTRIBUTING.md) for setup, checks and contribution expectations.

- Keep generic engine and agent capabilities in Core and product integration in Lokiravia.
- Preserve stable backlog IDs, dependencies and product acceptance gates.
- Inspect the current diff, preserve unrelated work and keep changes focused.
- Run checks appropriate to the change and report their actual scope and failures.
- Keep credentials, private briefs, books, extraction caches and machine-specific data out of Git.
- Preserve the product's human approval, audit and dry-run boundaries.

Development uses ordinary Git branches and pull requests. No named-computer registration or shared Git task claim is required.
