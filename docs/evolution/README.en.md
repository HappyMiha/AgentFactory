**Start with the [unified implementation order](implementation-order.en.md) and [exact scope of the first releases](first-releases.en.md).** The plan reconciles 280 requirements across both products; the 65 new cards are integrated with existing work. This is a plan, not an accepted runtime.

Documentation portfolio · revision 2026-09-10 · **E0 / proposed**. 35 new Core cards; 65 together with Lokiravia. The new RSI/LW requirements have not been implemented; existing legacy components are accounted for separately. Current alpha limitations, backlogs and release gates remain in force.

Core should improve its own code, harness, tools, memory, UX, research methods and the next optimiser. Each accepted generation is bound to an immutable subject, independent evidence, a metric defined before the run and a recovery path. Lokiravia is one consumer; Core's standalone value must be demonstrated without a finished game.

New pass Q05: [how Core generations and worlds recover from failures](recovery-contract.en.md) — 16 static scenarios, precise authority and a coherent state switch.
