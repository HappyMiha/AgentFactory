Три окремі шкали. Докази — у беклозі записано, що саме зроблено для задачі. Згадки в main — ID задачі згаданий у повідомленні коміту; це не доводить наявність чи завершеність реалізації. Прийнято — це заявлено в беклозі проти release gate, і без доказів беклог не може цього заявити. Жодна шкала не виводиться з іншої. Згадка в коміті не знімає залежностей. Готовність у цьому звіті не замінює перевірку релізних умов і дозволів.

Відсоток зважений за розміром задачі (S=2, M=5, L=10 умовних одиниць; без мітки — 5). Це охоплення планового беклогу, а не готовий продукт.
