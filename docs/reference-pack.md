# Software Engineering reference pack

AF-025 packages the proven single-node coding path as a product-neutral AF-024 capability. The pack payload references the existing managed worktree, Worker Runtime, candidate artifact, deterministic validator, independent evaluation, and coding-delivery services; it does not clone their authority or persistence logic.

The release envelope requires non-empty trace references for requirements, work items, Blueprint decisions, ADRs, test evidence, and accepted independent-review verdicts. These references remain separate from the pack manifest so the signed capability stays reproducible while each release remains attributable to the mission evidence that justified it.

Dependency evidence binds the signed AF-024 pack version and the existing eight-role Software Engineering role pack. Security evidence records the exact read/project/artifact/test permissions, verified signature, and independent-review references. Rollback evidence records disable, previous-version restore, contract/role digest verification, and mission-history retention. Publication is a human release-authority transition after the candidate release envelope is approved.
